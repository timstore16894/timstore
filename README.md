# 🟣 timstore — Інтернет-магазин (Чорно-фіолетовий стиль)

Сучасний, адаптивний сайт-магазин для бренду **timstore** з неоновим чорно-фіолетовим оформленням, динамічним каталогом, кошиком покупця та формою швидкого замовлення.

---

## 🚀 Як відкрити та запустити сайт

### Варіант 1: Прямий запуск
Просто двічі клікніть файл [`index.html`](file:///C:/Users/Irina/.gemini/antigravity/scratch/timstore/index.html) у провіднику, і він відкриється у вашому улюбленому браузері (Chrome, Edge, Firefox).

### Варіант 2: Локальний веб-сервер (рекомендовано)
У папці `C:\Users\Irina\.gemini\antigravity\scratch\timstore` виконайте у терміналі:
```bash
python -m http.server 3000
```
та відкрийте у браузері [http://localhost:3000](http://localhost:3000).

---

## 🎨 Як замінити логотип на свій
1. Збережіть файл вашого логотипу (у форматі `.png` або `.svg`).
2. Скопіюйте його в папку [`assets/`](file:///C:/Users/Irina/.gemini/antigravity/scratch/timstore/assets/) під назвою `logo.png` (або `logo.svg`).
3. Якщо розширення вашого файлу `.png`, у файлі [`index.html`](file:///C:/Users/Irina/.gemini/antigravity/scratch/timstore/index.html) замініть `assets/logo.svg` на `assets/logo.png`. Також ви можете просто надіслати логотип сюди в чат, і я підключу його автоматично!

## ⚙️ Функціонал сайту
- **Чорно-фіолетова колірна палітра**: неонові градієнти, скляні ефекти (Glassmorphism), підсвічування кнопок.
- **Інтерактивний кошик**: підрахунок кількості, суми замовлення, збереження стану в пам'яті браузера (LocalStorage).
- **Фільтрація та живий пошук**: швидкий пошук за категоріями або назвами товарів.
- **Швидкий перегляд товару**: модальне вікно з детальним описом та характеристиками.
- **Оформлення замовлення**: форма для Нової Пошти, вибір накладеного платежу чи онлайн-оплати, модальне вікно підтвердження.
